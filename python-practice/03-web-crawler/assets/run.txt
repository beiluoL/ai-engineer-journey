# 03 网站内容爬虫 —— 本地 fixture 站点 + 真实 HTTP 请求

① 生成 fixture 站点
   → .site/ 下 5 个页面（42 号种子，每次内容一致）

② 起本地 HTTP 服务（端口交给系统选，避免撞端口）
   → http://127.0.0.1:58591/
   注：/page-2.html 的第 1 次访问会返回 503，这是故意的

③ 开始爬取（广度优先，白名单只跟 index 与 /page-N.html）
  [ 1] GET /
       ✓ 200（0.5 KB）解析出 0 本书，新发现 3 个链接（白名单过滤掉 2 个）
  [ 2] GET /page-1.html
       ✓ 200（1.9 KB）解析出 6 本书，新发现 1 个链接（白名单过滤掉 1 个）
  [ 3] GET /page-2.html
       ↩ 503 服务端说「稍后再来」，等 0.5s 重试
       ✓ 200（1.8 KB）解析出 6 本书，新发现 1 个链接（白名单过滤掉 1 个）
  [ 4] GET /page-3.html
       ✓ 200（1.9 KB）解析出 6 本书，新发现 1 个链接（白名单过滤掉 1 个）
  [ 5] GET /page-4.html
       ⊘ 404，跳过（死链，重试没有意义）

④ 抓取结果
   访问页面 5 个 ｜ 失败 1 个 ｜ 重试 1 次
