数值稳定性：为什么 softmax 要先减 max
  logits = [1000. 1001.  999.]
  naive  exp(x) : [inf inf inf]   -> 结果 [nan nan nan]  <- inf/inf = nan，梯度直接炸掉
  stable exp(x-max): 结果 [0.2447 0.6652 0.09  ]   和为 1.000000
  数学上等价：exp(x_i)/sum(exp(x_j)) = exp(x_i-c)/sum(exp(x_j-c))，c 任意常数

交叉熵损失：loss = -log p(正确 token)
正确 token    logit    p        loss=-log p
猫           2.0      0.6381   0.4493   
狗           1.0      0.2347   1.4493   
鱼           0.1      0.0954   2.3493   
鸟           -1.0     0.0318   3.4493   

  观察：正确 token 的 logit 越高 -> 概率越大 -> loss 越小
  极端情况：p=1.0 -> loss=-0.0000（完美预测）; p=0.01 -> loss=4.6052
