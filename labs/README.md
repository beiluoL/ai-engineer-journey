# Labs — 实验

> Curriculum 回答「学什么」，Labs 回答「怎么通过小实验验证」。

## 规范

每个 Lab 对应一个小主题，独立可运行：

```text
labs/
├── 01-list-mutation/
│   └── main.py        # 单个 Python 脚本，演示 list 可变行为
├── 02-json-serialization/
│   └── main.py        # dict ↔ JSON 互转
└── ...
```

## 与 Curriculum 的关系

```text
Curriculum Lesson
      ↓
读完概念
      ↓
Lab
      ↓
动手验证
      ↓
理解更深
```
