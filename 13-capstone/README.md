# 13-capstone — Phase 13：Capstone

> 毕业项目：综合 Vue + FastAPI + RAG + Agent + vLLM 交付一个完整 AI 产品。

## 这一阶段学什么

- 全栈架构设计与选型
- Vue 前端 + FastAPI 后端整合
- RAG 知识库接入
- Agent 多步任务编排
- vLLM 模型服务化
- 端到端部署与文档产出

## 为什么学

前 12 阶段学了单点技能，Capstone 把它们串成完整产品：从需求、架构、编码、模型、部署到文档，模拟真实 AI 工程师的工作全流程，形成可展示的作品集。

## 前置知识

- 全部 Phase 0 ~ Phase 12

## 核心技能

- 设计完整 AI 产品架构
- 整合前端、后端、模型、知识库
- 编排 Agent 完成复杂任务
- 容器化部署整套系统
- 写产品文档与说明
- 独立交付一个可演示的 AI 应用

## 项目

| 项目 | 说明 |
|------|------|
| Capstone | 综合产品：Vue + FastAPI + RAG + Agent + vLLM |

## 完成标准

- Capstone 产品可演示、可部署
- 包含架构图与说明文档
- 至少集成 RAG / Agent / 模型服务三块
- 完成一次端到端用户场景验证
