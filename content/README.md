# content/ — 自媒体内容素材

> 每完成一个阶段，自动沉淀文章/图示/脚本素材。写作原则：面向初学者、少 AI 套话、
> 多真实代码、多真实问题、多实验、多踩坑、不堆术语。

```text
articles/  文章（每项目至少：概念篇 / 实战篇 / 踩坑篇 / 复盘篇 / 进阶篇）
diagrams/  架构图与数据流图（ASCII / Mermaid 优先）
scripts/   视频口播稿
notes/     过程笔记
videos/    视频成片与分镜
```
