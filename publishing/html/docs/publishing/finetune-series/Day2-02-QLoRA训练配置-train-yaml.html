一、先理解 train.yaml 是什么

如果说：

dataset_info.json

是：

数据说明书

那么：

train.yaml

就是：

训练计划书

它告诉训练程序：

例如：

我要训练：

模型：
Qwen2.5-3B-Instruct

数据：
java_interview

方法：
LoRA

训练：
3轮

保存：
java-lora

二、进入 LLaMA-Factory

Colab执行：

%cd /content/LLaMA-Factory

确认：

!pwd

应该：

/content/LLaMA-Factory

三、查看官方训练模板

LLaMA-Factory 已经准备好了很多例子。

查看：

!ls examples/train_lora

你会看到：

类似：

qwen2_lora_sft.yaml
llama3_lora_sft.yaml

我们参考它。

查看 Qwen 示例：

!cat examples/train_lora/qwen2_lora_sft.yaml

里面很多参数。

第一次不用全部理解。

四、创建自己的配置文件

创建：

train_java.yaml

位置：

/content/LLaMA-Factory/train_java.yaml

Colab里面创建：

%%writefile train_java.yaml


### 模型
model_name_or_path: Qwen/Qwen2.5-3B-Instruct


### 数据
dataset: java_interview

template: qwen


### 训练阶段
stage: sft

do_train: true


### 微调方式
finetuning_type: lora


### LoRA参数
lora_rank: 8

lora_alpha: 16

lora_dropout: 0.05


### 训练参数
learning_rate: 2.0e-4

num_train_epochs: 3

cutoff_len: 1024


### batch
per_device_train_batch_size: 2

gradient_accumulation_steps: 4


### 保存
output_dir: ./output/java-interview-lora


### 日志
logging_steps: 10

save_steps: 100


### GPU优化
fp16: true

运行后：

看到：

Writing train_java.yaml

五、逐个解释关键参数

1. model_name_or_path

model_name_or_path:
 Qwen/Qwen2.5-3B-Instruct

意思：

基础模型。

现在：

Qwen
+
你的数据
=
新的能力

2. dataset

dataset:
 java_interview

对应：

刚才注册：

"java_interview"

也就是：

dataset_info.json

        ↓

找到

java_interview.json

3. template

template:
 qwen

非常重要。

不同模型聊天格式不同。

例如：

Qwen：

<|im_start|>system

<|im_start|>user

<|im_start|>assistant

Llama：

格式不同。

所以告诉框架：

使用 Qwen 对话模板。

4. stage

stage:
 sft

SFT：

Supervised Fine-Tuning【监督微调】

目前你的训练：

就是：

输入：

HashMap为什么线程不安全？

输出：

标准面试答案

5. finetuning_type

finetuning_type:
 lora

表示：

不要改整个模型。

原模型：

Qwen

30亿参数

冻结

新增：

LoRA参数

训练

6. LoRA参数

lora_rank

lora_rank:8

理解：

LoRA容量。

越大：

能力可能越强。

但是：

显存增加。

第一次：

8即可。

learning_rate

learning_rate:2e-4

学习速度。

太大：

容易学坏。

太小：

学不动。

num_train_epochs

num_train_epochs:3

训练轮数。

你的数据：

500-1000条。

3轮够。
