不要写：

❌

调用了ChatGPT API。

太普通。

写：

✅

AI知识库助手

基于Spring Boot、LangChain4j和Milvus构建企业级RAG知识库系统，实现文档解析、智能切片、Embedding向量检索、Rerank优化和大模型生成回答。

企业AI平台

构建私有大模型应用平台，通过vLLM部署Qwen模型，结合LLM Gateway实现模型路由、成本控制和服务监控。
