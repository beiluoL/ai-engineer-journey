Loss 是什么？

← 上一节为什么只有0.07%参数训练？下一节 →1. batch 调小

Loss：

损失值【模型错误程度】

简单理解：

模型回答：

HashMap为什么线程不安全？

第一次：

输出：

HashMap是一种Map

和你的标准答案差距大。

Loss：

高。

训练后：

输出：

因为HashMap没有同步机制...

接近答案。

Loss：

下降。

七、如果出现显存不足

错误：

CUDA out of memory

解决：

修改：

1. batch 调小

← 上一节Loss 是什么？下一节 →2. cutoff_len降低

原：

per_device_train_batch_size:2

改：

per_device_train_batch_size:1

2. cutoff_len降低

← 上一节1. batch 调小下一节 →3. 开启4bit QLoRA

原：

cutoff_len:1024

改：

cutoff_len:512

3. 开启4bit QLoRA

← 上一节2. cutoff_len降低下一节 →adapter_model.safetensors

修改：

增加：

quantization_bit: 4

完整：

quantization_bit: 4

finetuning_type: lora

十、训练完成后测试

← 上一节微调前下一节 →第一次微调效果验证

1. put并发覆盖
