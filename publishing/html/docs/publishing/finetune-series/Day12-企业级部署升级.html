四、Docker Compose是什么？

简单理解：

以前：

启动服务：

docker run xxx
docker run xxx
docker run xxx

现在：

一个文件：

docker-compose.yml

定义：

有什么服务

用什么镜像

多少资源

怎么连接

然后：

一句：

docker compose up

全部启动。

五、部署 vLLM 容器

创建：

vim docker-compose.yml

第一版：

version: "3.8"


services:

  vllm:

    image:
      vllm/vllm-openai:latest


    container_name:
      qwen-vllm


    restart:
      always


    runtime:
      nvidia


    ports:

      - "8000:8000"


    volumes:

      - ./models:/models


    command:

      >
      --model /models/qwen2.5-7b

      --host 0.0.0.0

      --port 8000

      --dtype auto

解释：

image

← 上一节文档开头下一节 →runtime
vllm/vllm-openai

官方 vLLM 镜像。

runtime

← 上一节image下一节 →volumes
nvidia

允许：

Docker使用GPU。

volumes

← 上一节runtime下一节 →GPU
./models:/models

宿主机：

/models

映射：

容器：

/models

八、Nginx作为入口

为什么需要？

不要让用户直接访问：

服务器IP:8000

应该：

https://ai.xxx.com

安装：

mkdir nginx

创建：

vim nginx/nginx.conf

配置：

server {


listen 80;


server_name ai.example.com;



location / {


proxy_pass 
http://vllm:8000;



proxy_set_header Host $host;


proxy_set_header X-Real-IP $remote_addr;


}

}

现在：

链路：

用户

↓

Nginx

↓

vLLM

十一、限流

为什么？

防止：

一个用户：

无限请求。

例如：

1000个请求：

瞬间打爆GPU。

Nginx：

limit_req_zone

$binary_remote_addr

zone=ai_limit:10m

rate=5r/s;

表示：

一个IP：

每秒最多5次。
