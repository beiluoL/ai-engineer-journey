三、GPU是什么？

GPU

← 上一节CPU下一节 →VRAM
← 上一节RAG下一节 →必须懂

英文：

Graphics Processing Unit

中文：

图形处理器。

最初：

负责游戏画面。

后来发现：

AI计算特别适合GPU。

为什么？

因为AI大量计算：

例如：

矩阵乘法。

普通：

GPU：

几千个小核心。

类比：

GPU：

10000个普通员工同时计算。

所以：

大模型训练/推理：

主要靠GPU。

四、显存是什么？

VRAM

← 上一节GPU下一节 →RAM

英文：

Video Random Access Memory

中文：

显存。

简单理解：

GPU自己的内存。

电脑内存：

给CPU使用。

GPU显存：

给GPU使用。

例如：

RTX4090：

24GB显存。

意思：

GPU里面有24GB高速空间。

为什么显存重要？

因为模型需要放进去。

例如：

Qwen 7B模型：

大约：

14GB FP16。

如果显存：

8GB。

加载不了。

关系：

模型大小

↓

需要显存

↓

决定GPU型号
