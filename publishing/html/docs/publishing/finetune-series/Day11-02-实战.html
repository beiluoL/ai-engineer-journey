安装：

重启 Docker：

systemctl restart docker

测试：

--gpus all \
nvidia/cuda:12.2.0-base \
nvidia-smi

成功：

RTX4090

说明：

Docker已经可以调用GPU。

十一、安装 vLLM

安装：

pip install vllm

检查：

vllm --version

十二、下载 Qwen 模型

这里有两种方式。

方法1：HuggingFace

← 上一节安装下一节 →方法2：ModelScope

安装：

pip install huggingface_hub

登录：

huggingface-cli login

输入Token。

下载：

huggingface-cli download \
Qwen/Qwen2.5-7B-Instruct \
--local-dir /data/models/qwen2.5-7b

目录：

/data/models/

└── qwen2.5-7b

    ├── config.json

    ├── model.safetensors

    └── tokenizer

方法2：ModelScope

← 上一节方法1：HuggingFace下一节 →1. Docker化

国内更快。

安装：

pip install modelscope

下载：

modelscope download \
--model Qwen/Qwen2.5-7B-Instruct \
--local_dir /data/models/qwen2.5-7b

十三、第一次启动 vLLM
