Project 07 — Open Source LLM

项目目标

← 上一节文档开头下一节 →为什么做这个项目

接触真实开源模型生态，在云端（Colab GPU）亲手跑通 Hugging Face 开源模型，理解加载 / 推理 / 量化 / 服务。

为什么做这个项目

← 上一节项目目标下一节 →解决什么问题

生产环境不可能每次都调商业 API。需要掌握如何加载、运行、对比开源模型，理解它们的限制和优势。

解决什么问题

运行方式（Colab 云端，零本地资源）

← 上一节项目演进下一节 →Milestones

路线决策（2026-09-29）：原计划在本机 M1 装 torch + 下模型，但本机磁盘仅剩 ~15GB 且用户要求「不要使用本地」。 改为 Colab 云端真跑：模型与算力都在 Colab 免费 T4 GPU 上，本机零磁盘/内存占用。 详见 notebooks/README.md 与 notebooks/p07_colab.ipynb。

微调路线（Java 面试专家）：在 Colab 免费 GPU 上用 LLaMA-Factory 对 Qwen2.5-1.5B 做 QLoRA SFT，产出 LoRA Adapter 并合并成完整模型。详见 notebooks/p07_finetune_java_interview.ipynb 与 scripts/。

调用管线 pipelines/（当前主线，已真实跑通）：本机跑不动 7B 权重（bf16 需 14.18 GiB）， 但「调用」不需要本地有卡。pipelines/ 走 DeepSeek OpenAI 兼容接口、由本机直接驱动， 6 个模块全部真实运行完毕，产出 6 张真实终端截图。详见 pipelines/README.md。

本机（只写代码）          Colab（跑模型）

   p07_colab.ipynb        Runtime=GPU, Run All
         ↓                      ↓
   回收真实输出       →    demos/out/colab_Mxx.txt
         ↓
   渲染截图 + 写 milestones/
