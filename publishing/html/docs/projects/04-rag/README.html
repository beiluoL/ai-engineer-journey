Project 04 — AI Knowledge Base / RAG Assistant

项目目标

← 上一节文档开头下一节 →为什么做这个项目

给 AI 加上外部知识，构建真正的 RAG【检索增强生成】系统。

为什么做这个项目

← 上一节项目目标下一节 →解决什么问题

LLM 有知识截止日期，而且幻觉不可避免。RAG 让模型能检索外部知识，是目前生产级 AI 应用的标配能力。

解决什么问题

← 上一节为什么做这个项目下一节 →最终能力
  • LLM 不知道最新信息（知识截止日期）
  • LLM 可能编造事实（幻觉）
  • 私有知识（文档 / 数据库）无法直接给 LLM 用
