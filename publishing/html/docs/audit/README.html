Audit — 仓库体检档案

一期一档。每期是一次真实运行的全面体检，所有数字都来自当场执行的命令， 不引用记忆、不做估算。工具：scripts/audit.py（可重复运行）。

与 check_links.py 的分工：后者只回答「链接指向的文件在不在」， 本目录回答「项目骨架、证据链、配图、文档漂移、密钥有没有问题」。

各期

期次报告结论
2026-09-30第 1 期：全仓库体检ERROR 1 · WARN 15 · INFO 11（@ 2014d85）；1180 项测试全绿、859 条链接零死链、零硬编码密钥

怎么用

python3 scripts/audit.py          # 全量体检
python3 scripts/audit.py --quick  # 跳过死链检查（较快）

退出码非 0 表示存在 ERROR 级问题，可以挂进 CI。

复现约定

  • 每期报告附真实运行截图（assets/ 下），原始输出存档为同名 .txt
  • 截图由 scripts/render_terminal.py 从真实 stdout 渲染，不手工绘制
  • 发现问题后不在报告里直接改仓库：报告只给清单和验收标准，改动单独提交
