09 · 数学基础：关键公式与推导思路

一句话结论：LLM 用到的数学其实不多——矩阵乘法、softmax、交叉熵、链式法则、几个优化器。 难的不是数学本身，而是把符号和工程实现对应起来。本章按"符号 → 公式 → 推导思路 → 实现注意"的顺序过一遍。

怎么读这一章：第 02/03/07 章已经把结论用掉了。本章是"回头补推导"的地方，第一次读可以跳读，第二遍再细看。

9.2 前置：三个必须熟练的运算

9.2.1 矩阵乘法与形状检查

(AB)ij=∑kAikBkj,⏟(m×k)A·⏟(k×p)B=⏟(m×p)AB

形状检查是调试的第一手段：算不出来 90% 是形状不对（内维必须相等）。

运算形状计算量
XW(n,d)×(d,d')→(n,d')2ndd' FLOPs
AB⊤(n,d)×(d,n)→(n,n)2n2d
逐元素形状必须相同O(n)

9.2.2 点积与余弦相似度

a·b=∑i=1daibi=‖a‖‖b‖cosθ

注意力里 q·k 就是用它衡量"方向一致程度"（含模长影响，所以缩放很关键，见 9.3）。

9.2.3 转置与广播

  • (AB)⊤=B⊤A⊤ —— 反向传播推导的基础
  • 广播（broadcast）：(n,1) 与 (1,m) 相加得到 (n,m)，掩码就是这么加的

9.3 Self-Attention 的缩放：为什么是 √d_k

← 上一节9.2 前置：三个必须熟练的运算下一节 →9.4 Softmax 与交叉熵：梯度为什么这么漂亮

结论：为了让注意力打分矩阵在初始化时保持单位方差，softmax 不至于饱和。

推导思路

前提假设：q 和 k 的各分量独立同分布，均值 0、方差 1（这是合理的初始化假设——现代网络的激活尺度控制就是朝这个方向设计的）。

第一步：计算单个乘积项的方差。

Var(qiki)=E[qi2ki2]-(E[qiki])2=E[qi2]E[ki2]-0=1·1=1

第二步：dk 个独立项求和，方差线性累加。

Var(∑i=1dkqiki)=∑i=1dkVar(qiki)=dk⟹标准差=dk

第三步：结论。点积的典型大小随 dk 增长。除以 dk 后方差回到 1：

Var(q·kdk)=dkdk=1

第四步：为什么方差重要——看 softmax 的行为。

softmax(z)i=ezi∑jezj
输入标准差softmax 输出梯度
≈ 1平滑分布，各位置都有权重健康
≫ 1（如 10）接近 one-hot；最大项独占∂p/∂z→0，饱和，学不动

真实数据验证（demos/02_self_attention.py）：未缩放时打分绝对值均值 1.457，除以 √d_k = 2.0 后降到 0.729——数值被"压"到合理区间。

顺带：Softmax 的雅可比矩阵（推导思路）

∂pi∂zj=pi(δij-pj)⟹∂L∂z=p-y(与交叉熵复合后)

这个"p-y"结果极其重要（见 9.4），也是为什么 softmax + 交叉熵的组合在框架里常常被合并成一个 op（cross_entropy_with_logits）—— 不只是为了数值稳定，也因为梯度形式特别简洁。

9.4 Softmax 与交叉熵：梯度为什么这么漂亮

← 上一节9.3 Self-Attention 的缩放：为什么是 √d_k下一节 →9.5 位置编码与 RoPE

9.4.1 Softmax 的数值稳定性

softmax(z)i=ezi-c∑jezj-c对任意常数c成立

取 c=maxjzj，指数项的取值范围被压到 (-∞,0]，永不溢出。真实实验见 第 01 章（logits=[1000,1001,999] 时 naive 版本得到 nan）。

9.4.2 交叉熵

单样本（正确类别为 y）：

L=-logpy=-logezy∑jezj=-zy+log∑jezj

这个形式叫 log-sum-exp，也是数值稳定实现的标准写法。

一个 batch：

L=-1N∑i=1Nlogpi,yi

9.4.3 梯度推导

对 logits 求导：

∂L∂zj=-∂zy∂zj+∂∂zjlog∑kezk=-δjy+ezj∑kezk=pj-δjy
∂L∂z=p-y

人话：梯度就是"预测分布 − 真实分布（one-hot）"。预测得越准，梯度越小；错得越离谱，梯度越大（但配合 softmax 有上界，不会爆炸）。这个结果也解释了为什么 softmax + CE 的组合训练如此稳定。

9.4.4 困惑度

PPL=exp(L)

推导：对一个长度为 T 的序列，其似然是 ∏tpt，取负对数再取指数就是"几何平均的倒数"：

PPL=(∏t=1T1pt)1/T=exp(-1T∑tlogpt)=eL

直觉：PPL 相当于"模型每次预测时，等价于在 PPL 个候选里均匀犹豫"。

9.5 位置编码与 RoPE

← 上一节9.4 Softmax 与交叉熵：梯度为什么这么漂亮下一节 →9.6 反向传播与自动微分

9.5.1 正弦位置编码

PE(pos,2i)=sin(pos100002i/d),PE(pos,2i+1)=cos(pos100002i/d)

定义角频率 ωi=10000-2i/d，则 PE(pos)=[sin(ω0pos),cos(ω0pos),sin(ω1pos),cos(ω1pos),…]

为什么能表达相对位置（推导思路）：利用和角公式

sin(ω(pos+k))&=sin(ωpos)cos(ωk)+cos(ωpos)sin(ωk)cos(ω(pos+k))&=cos(ωpos)cos(ωk)-sin(ωpos)sin(ωk)

写成矩阵形式：

[sin(ω(pos+k))cos(ω(pos+k))]=⏟[cos(ωk)sin(ωk)-sin(ωk)cos(ωk)]只与k有关的旋转矩阵[sin(ωpos)cos(ωpos)]

结论：PE(pos+k) 是 PE(pos) 的一个只依赖 k 的线性变换。所以注意力里 q⊤k 能自然地表达相对距离——这就是 demos/04_positional_encoding.py 里"同一 k 下不同 pos 点积完全相同"（7.4852 × 4）的数学原因。

9.5.2 RoPE：把旋转搬到 Q/K 上

RoPE 直接对 Q、K 施加旋转（而非加在输入上）：

qm'=RΘ,mqm,kn'=RΘ,nkn

对二维子空间 (2i,2i+1) 的旋转矩阵：

R(i)θi,m=[cos(mθi)-sin(mθi)sin(mθi)cos(mθi)],θi=10000-2i/d

关键性质（这是 RoPE 的全部价值）：

qm'⊤kn'=(Rmqm)⊤(Rnkn)=qm⊤Rm⊤Rnkn=qm⊤Rn-mkn

因为 R⊤mRn=Rn-m（旋转矩阵的正交性与可加性）。内积只依赖 n-m，即相对位置。 而且这个操作不增加任何参数，也不改变向量模长（正交变换）。

实现细节说明
应用到哪些位置只对 Q、K 旋转，V 不动
计算方式用 cos/sin 预计算表，偶数维用 sin、奇数维用 cos 配对旋转
长上下文扩展位置插值 / 调整 θi 基底（NTK-aware）/ YaRN

9.6 反向传播与自动微分

← 上一节9.5 位置编码与 RoPE下一节 →9.7 优化器：从 SGD 到 AdamW

9.6.1 链式法则

∂L∂θ=∂L∂z·∂z∂h·∂h∂θ

反向传播 = 按计算图的逆序，反复应用链式法则，同时复用中间梯度（所以它比"逐个参数数值求导"快几个数量级）。

9.6.2 计算图（前向 → 反向）

流程图（简化）：

  • X — X
  • W1 — @ W1
  • H — h1
  • ACT — 激活
  • W2 — @ W2
  • Z — logits z
  • CE — softmax + CE
  • T — target y
  • L — loss L

虚线是反向传播方向。工程上一个必须记住的结论：

每个算子的反向传播，本质上都是"用上游梯度 × 本算子的局部雅可比"，而矩阵乘的反向就是"另一侧的转置"。 例：z=hW 时，∂L∂W=h⊤∂L∂z，∂L∂h=∂L∂zW⊤。

9.6.3 为什么必须用 autograd

以 7B 模型为例，参数量 7×10⁹：

方式代价可行性
数值求导（逐参数扰动）每个参数需要 2 次前向 → 1.4×10¹⁰ 次前向❌ 完全不可行
符号求导（推导闭式）表达式爆炸❌ 不现实
反向传播 + autograd约 1 次前向的 2 倍计算量✅ 唯一可行

这也解释了 C ≈ 6ND 的由来：前向 2ND + 反向 4ND = 6ND。

9.6.4 梯度累积与裁剪

GPU 装不下大 batch 时：

geffective=1K∑k=1Kgk（K 个 micro-batch 累积后再更新）

梯度裁剪（防爆炸）：

g←g·min(1,c‖g‖)(c通常取1.0)

9.8 概率与信息论速查

← 上一节9.7 优化器：从 SGD 到 AdamW下一节 →9.9 手推清单（面试前自查）

9.8.1 熵、交叉熵、KL 散度

H(p)=-∑ipilogpiH(p,q)=-∑ipilogqiKL(p‖q)=∑ipilogpiqi

三者的关系（这是理解"为什么训练目标合理"的关键）：

H(p,q)=H(p)+KL(p‖q)
  • H(p)：真实分布的固有不确定性（不可约损失 L∞）
  • KL(p‖q)：模型分布与真实分布的差距（我们真正想最小化的东西）
  • 由于 H(p) 与参数无关，最小化交叉熵 ≡ 最小化 KL 散度
性质KL 散度
非负性KL≥0，当且仅当 p=q 时为 0
不对称KL(p‖q)≠KL(q‖p)
前向 KL（KL(p‖q)）惩罚"p>0 但 q≈0"→ 倾向覆盖所有模式（mode-covering）
反向 KL（KL(q‖p)）惩罚"q>0 但 p≈0"→ 倾向只抓一个模式（mode-seeking）

对齐（第 08 章）里用的 KL 惩罚是 KL(πθ‖πref)——注意方向很重要，它约束的是"新模型不要跑到参考模型概率极低的地方去"。

9.8.2 采样：温度与 top-p 的数学

温度采样：

pi=exp(zi/T)∑jexp(zj/T)

T 的极限行为（值得记）：

T极限证明思路
T→0+p→ one-hot（argmax）最大项占指数主导
T→∞p→ 均匀分布zi/T→0，所有 e0=1

Top-p（核采样）：按概率降序排列，取最小集合 S 满足

∑i∈Spi≥p

然后把 S 外概率置 0 并重新归一化。

9.8.3 奖励模型里的 Bradley-Terry

见 第 08 章 8.2.1，本质是用 sigmoid 把"分数差"映射为偏好概率：

P(yw≻yl)=σ(rw-rl)
