cd llm-fundamentals
pip install -r demos/requirements.txt
python3 demos/02_self_attention.py      # 手算注意力，看清每一步

学习路线：三个阶段，一条主线

← 上一节这个目录写给谁下一节 →章节地图

流程图（简化）：

  • P1 — 阶段一 · 看懂一个 token 的一生
  • A1 — 01 语言模型基础 token → embedding → logits → 概率 训练目标 = 交叉熵
  • P2 — 阶段二 · 看懂一台机器
  • A2 — 02 注意力机制 QKV / 缩放 / 掩码 / 多头
  • A3 — 03 Transformer 架构 残差 / LayerNorm / FFN / 位置编码
  • A4 — 09 数学基础 公式推导 / 反向传播 / 优化器
  • P3 — 阶段三 · 看懂一条产业链
  • A5 — 04 预训练 数据 / 目标 / 并行 / 算力
  • A6 — 05 微调 SFT / LoRA / QLoRA
  • A7 — 06 涌现与缩放定律 规模带来什么
  • A8 — 08 对齐 RLHF / DPO
  • A9 — 07 解码与推理 KV Cache / 量化 / 批处理

一句话主线：

语言模型 = 用注意力机制在上下文里找相关信息，预测下一个 token。 预训练让它学会语言，微调让它学会任务，对齐让它学会"好好说话"，推理优化让它跑得动。

每章的结构约定

每章都按同一套结构写，方便跳读：

1. 一句话结论         —— 这章解决什么问题
2. 直觉               —— 先建立"人话版"理解
3. 机制与公式         —— 公式 + 符号表
4. 配图               —— Mermaid / 表格 / 真实运行截图
5. 常被误解的点       —— 面试高频混淆
6. 动手               —— 对应 demo 脚本
7. 自查问题           —— 能答上来才算懂

阅读建议
