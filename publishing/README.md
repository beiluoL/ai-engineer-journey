# Publishing — 对外内容

> Publishing 是面向外部发布的二次加工内容，不是第二套课程正文。

## 来源

```text
Curriculum Lesson
        ↓
学习 / 实践 / 总结
        ↓
Publishing
```

## 目录

```text
articles/   技术文章（学习笔记 / 实战总结 / 踩坑复盘）
videos/     视频口播稿与分镜
diagrams/   架构图与数据流图（ASCII / Mermaid 优先）
social/     社媒短内容
```

## 原则

- 面向初学者，少 AI 套话
- 多真实代码、多真实问题
- 不堆术语，不讲"原理天书"
- 一次只讲一个知识点
