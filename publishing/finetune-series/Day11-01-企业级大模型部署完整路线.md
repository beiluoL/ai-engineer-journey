# 第六部分：GPU显存怎么计算？

核心公式：

```
模型参数 × 精度
```

---

例如：

7B模型：

参数：

70亿

FP16:

```
7B × 2 bytes

≈14GB
```

实际：

需要：

20GB左右。

---

INT4：

```
7B × 0.5 bytes

≈3.5GB
```

实际：

8～10GB。

所以：

量化非常重要。

# 第八部分：使用 vLLM 部署模型

为什么 vLLM？

因为：

- 高吞吐
    
- Continuous Batching【连续批处理】
    
- KV Cache优化
    
- OpenAI API兼容
    

([GitHub](https://github.com/QwenLM/Qwen3/blob/main/docs/source/deployment/vllm.md?utm_source=chatgpt.com "Qwen3/docs/source/deployment/vllm.md at main · QwenLM/Qwen3 · GitHub"))

---

安装：

```bash
pip install vllm
```

---

启动：

例如：

Qwen2.5-7B

```bash
vllm serve Qwen/Qwen2.5-7B-Instruct \
--host 0.0.0.0 \
--port 8000
```

Qwen官方示例也是通过 `vllm serve` 提供 API 服务。([GitHub](https://github.com/QwenLM/Qwen3/blob/main/docs/source/deployment/vllm.md?utm_source=chatgpt.com "Qwen3/docs/source/deployment/vllm.md at main · QwenLM/Qwen3 · GitHub"))

---

启动后：

接口：

```
http://服务器IP:8000/v1/chat/completions
```

---

测试：

```bash
curl http://localhost:8000/v1/chat/completions \
-H "Content-Type: application/json" \
-d '
{
"model":"Qwen2.5-7B-Instruct",
"messages":[
{
"role":"user",
"content":"解释HashMap"
}
]
}
'
```

返回：

```json
{
"choices":[
{
"message":{
"content":"..."
}
}
]
}
```
