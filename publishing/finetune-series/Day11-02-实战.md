# 九、安装 NVIDIA Docker支持

Docker默认不能使用GPU。

需要：

NVIDIA Container Toolkit。

安装：

```bash
apt install nvidia-container-toolkit -y
```

重启 Docker：

```bash
systemctl restart docker
```

---

测试：

```bash
docker run \
--gpus all \
nvidia/cuda:12.2.0-base \
nvidia-smi
```

成功：

看到：

```
RTX4090
```

说明：

Docker已经可以调用GPU。

# 十二、下载 Qwen 模型

这里有两种方式。

---

## 方法1：HuggingFace

安装：

```bash
pip install huggingface_hub
```

登录：

```bash
huggingface-cli login
```

输入Token。

---

下载：

```bash
huggingface-cli download \
Qwen/Qwen2.5-7B-Instruct \
--local-dir /data/models/qwen2.5-7b
```

目录：

```
/data/models/

└── qwen2.5-7b

    ├── config.json

    ├── model.safetensors

    └── tokenizer
```

---

## 方法2：ModelScope

国内更快。

安装：

```bash
pip install modelscope
```

下载：

```bash
modelscope download \
--model Qwen/Qwen2.5-7B-Instruct \
--local_dir /data/models/qwen2.5-7b
```

---
