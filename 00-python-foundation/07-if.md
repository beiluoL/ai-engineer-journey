# 07 — If：条件判断

## 它是什么
分支逻辑。Python 版本最大的冲击：**缩进就是语法块，没有花括号**。

## Java 开发者如何理解

```java
// Java
if (key == null) {
    throw new IllegalArgumentException("key is null");
} else if (key.isEmpty()) {
    ...
} else {
    ...
}
```

```python
# Python —— 无括号、无花括号、冒号 + 缩进（约定 4 空格）
if api_key is None:
    raise ValueError("API Key 未设置")
elif api_key == "":
    ...
else:
    ...
```

**关键差异：Python 用 `elif` 不是 `else if`；条件不用括号；冒号不能少。**

## 真值判断（Truthy/Falsy）—— Python 特色

`if x:` 不只是判断布尔，空值自动为假：

```python
# Falsy：0, 0.0, "", [], {}, None, False
# 其余都是 Truthy

if not user_input:          # 等价 Java 的 isEmpty() 判断，最常用
    print("输入为空")

if messages:                # 列表非空才发请求
    call_llm(messages)
```

## 最小可运行 Demo

```python
# demo_if.py —— Project 01 的输入校验逻辑
question = input("你的问题: ").strip()

if not question:
    print("问题不能为空，请重新输入")
elif len(question) > 500:
    print("问题太长了，请精简到 500 字以内")
else:
    print(f"收到问题：{question}")
    mode = "详细" if "--verbose" in question else "简洁"   # 三元表达式
    print(f"回答模式：{mode}")
```

Python 三元表达式格式：`A if 条件 else B`（顺序和 Java 相反：Java 是 `条件 ? A : B`）。

## 常见错误

1. **忘记冒号**：`if x > 1` 换行 → SyntaxError，行尾必须有 `:`。
2. **缩进混乱**：Tab 和空格混用 → `IndentationError` 或诡异逻辑。统一 4 空格（IDE 自动处理）。
3. **`=` 写成 `==`**：Python 的 `if x = 5` 直接语法错误（比 Java 严格，反而是好事）。
4. **判断 None 用 `==`**：规范写法 `if x is None:` / `if x is not None:`。
5. **空串误判为有效**：`if user_input:` 会把 `"  "` 当真，注意先 `.strip()`。

## 常见面试问题
- Python 怎么实现 switch？→ 3.10+ 有 `match/case` 结构化匹配；此前用 if/elif 或 dict 分发。

## 练习
1. 判断输入的 API Key：为 None、为空、正常三种情况分别打印。
2. 用三元表达式把 temperature 归一化：大于 1 取 1，否则原值。
3. 用 `if not messages:` 实现空历史不发请求。
