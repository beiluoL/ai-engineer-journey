# Project 09 — Evaluation & Inference

## 项目目标

掌握模型评估、量化和高性能推理服务化。

## 为什么需要这个项目

训练完模型只是第一步。上线前必须评估效果、量化压缩、做高性能推理服务——这些是 AI 工程师区别于调参侠的关键能力。

## 最终能力

- 评估集设计（自动 + 人工）
- Benchmark（MMLU / HumanEval）
- INT8 / INT4 量化
- vLLM / Batching / PagedAttention
- KV Cache 管理
- 并发推理服务

## 项目演进

↓ 评估 + 优化 + 服务化
Production-ready Inference
