# Project 04 — Personal RAG

## 项目目标

给 AI 加上外部知识，构建真正的 RAG 系统。

## 为什么需要这个项目

LLM 有知识截止日期，而且幻觉不可避免。RAG 让模型能检索外部知识，是目前生产级 AI 应用的标配能力。

## 最终能力

- Token 切分与 Chunk 策略
- Embedding（文本向量化）
- 向量数据库（Chroma / FAISS）
- Retrieval 检索
- Rerank 重排序
- 完整 RAG Pipeline
