=== 1. 同样一段意思，中文和英文的 token 差多少 ===
  [中文] 今天天气不错，我们一起出去走走吧。
    字符数 17 / UTF-8 字节 51 / 估算 token 15
    1 token ≈ 1.13 个字符（用字符数当 token 会多算 1.13 倍）
  [英文] The quick brown fox jumps over the lazy dog.
    字符数 44 / UTF-8 字节 44 / 估算 token 13
    1 token ≈ 3.38 个字符（用字符数当 token 会多算 3.38 倍）
  [混排] 把 FastAPI 里的 client.chat 改成 messages 列表，报错就没了。
    字符数 46 / UTF-8 字节 74 / 估算 token 21
    1 token ≈ 2.19 个字符（用字符数当 token 会多算 2.19 倍）

=== 4. 成本（示例单价：输入 1 元 / 输出 2 元 每百万 token）===
  单轮新增历史 ≈ 69 token
  第 1 轮（没有历史）：输入 69 + 输出 39 token → 0.000147 元
  10 轮累计：输入 3,795 token + 输出 390 token → 0.0046 元（55 倍单轮输入）
  30 轮累计：输入 32,085 token + 输出 1,170 token → 0.0344 元（465 倍单轮输入）
  单价对比：输出比输入贵 2 倍，所以「让模型少说废话」直接省钱
