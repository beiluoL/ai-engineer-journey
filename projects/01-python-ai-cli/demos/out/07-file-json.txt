===== 3. with open(...) =====
写完了，但还没 close，此时 f.closed = False
手动 close 之后，f.closed = True
>>> 忘了 close 会怎样？文件句柄占着不放，
>>> Windows 上甚至没法删，而且内容可能还没真正落盘。
  在 with 里面，f2.closed = False
  出了 with，f2.closed = True
>>> with 会在代码块结束时自动 close，不用担心忘记。

三种模式速查：
   'r' read   = 读，文件必须存在
   'w' write  = 写，不存在就新建，存在就清空
   'a' append = 追加，不存在就新建，存在就写到末尾
   还有 'r+'(读写) / 'w+'(新建读写) / 'rb'(二进制读) 等等

================ 小结 ================
1. 用 pathlib.Path，路径拼装不用再纠结斜杠。
2. 'r' 读 / 'w' 覆盖写 / 'a' 追加，读写都要写 encoding='utf-8'。
3. 一律用 with open(...) as f，它会帮你 close。
4. json.dump 写文件、json.load 读文件；dumps/loads 只处理字符串。
5. 存中文加 ensure_ascii=False，调 indent=2 方便人肉查看。
6. 历史记录文件第一次读会 FileNotFoundError，属于正常情况。
