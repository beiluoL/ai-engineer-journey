===== 1. 变量：给数据绑定一个名字 =====
name = 'Beiluo'
role = 'Java 开发工程师'
age = 29
study_hours = 3.5
learning_ai = True

===== 2. type()：Python 怎么知道数据是什么类型 =====
'Beiluo' 的类型是 str
'Java 开发工程师' 的类型是 str
29 的类型是 int
3.5 的类型是 float
True 的类型是 bool

===== 3. 一行给多个变量赋值 =====
x, y = 1, 2
交换后 x, y = 2, 1
count=3, price=9.5, title='Python 入门'

===== 4. 变量重新赋值：id() 会变吗 =====
现在 a = 100   -> 对象 id = 4343481312
再赋 100       -> 对象 id = 4343481312
改成 "hello"   -> 对象 id = 4312775152
变量名更像贴在对象上的标签：换成另一个对象，id 就变。

===== 5. input()：拿用户输入，但永远拿到字符串 =====
请输入年龄：（没有检测到输入，使用示例数据：29）

raw_age = '29'  类型是 str
int() 之后 age = 29  类型是 int
请输入每天学习时间：（没有检测到输入，使用示例数据：3.5）

study_hours = '3.5'  类型是 str
float() 之后 study_hours = 3.5  类型是 float

===== 6. f-string：把变量放进文本 =====
姓名：Beiluo
职业：Java 开发工程师
每天学习：3.5 小时
每周学习：24.5 小时
每周学习（保留一位小数）：24.5 小时
完成度：80%
编号补零：007
大括号里直接算：3.5 * 7 = 24.5
名字有 6 个字符

===== 7. 动态类型：同一个名字可以换类型 =====
value = 10 的时候 -> int
value = "hello" 的时候 -> str
Java 写 `String name` / `int age`；Python 只写名字，运行时才决定类型。
