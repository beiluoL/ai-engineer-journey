===== 6. __name__ 是什么 =====
当前这个 demo 文件的 __name__ = __main__
当直接运行 python3 一个 .py 文件时，它的 __name__ 是 '__main__'；
但当被 import 时，它的 __name__ 就是模块名。

================ 小结 ================
1. 模块就是一个 .py 文件，import 时会把文件跑一遍。
2. from x import y 和 import x.y 都能用，看场景。
3. 包 = 带 __init__.py 的目录，点号的层级就是目录层级。
4. __name__ == "__main__" 用来区分「被导入」和「被直接运行」。
5. sys.path 是 Python 找模块的搜索路径清单。
