分词器把文本切成 token，再把 token 映射成整数 id，这是模型读懂文本的第一道门。
BPE 从字符出发，反复合并出现频率最高的一对相邻符号，直到词表达到设定大小。
词表越大，句子被切出的 token 越少，压缩率越高，但 embedding 矩阵也就越大。
训练 BPE 时统计的是相邻符号对的共现频次，合并规则按顺序回放即可复现分词结果。
Embedding 是一张查找表，第 i 行就是第 i 个 token 的向量表示。
位置编码给每个位置一个向量，让没有循环结构的 Transformer 知道 token 的先后顺序。
正弦位置编码用不同频率的 sin 和 cos 构造，不引入任何可训练参数。
自注意力的公式是 softmax(QKᵀ / √d) V，除以根号 d 是为了稳住方差。
因果掩码把未来位置挡住，保证第 t 个位置只能看到第 t 个及之前的 token。
多头注意力把 d_model 切成 h 份，每份独立算注意力，最后拼接再线性映射。
Transformer Block 采用 Pre-LN：先层归一化再进注意力，残差连接把输入直接加到输出上。
前馈网络先升维到 d_ff 再降回 d_model，激活函数常用 ReLU 或 GELU。
Decoder-Only 结构把 N 个 Block 堆叠起来，最后一层线性投影回词表维度得到 logits。
自回归训练的目标是：用前 L 个 token 预测第 L+1 个 token，逐位错开。
交叉熵损失只在真实 token 上计算，padding 位置要用 mask 排除掉。
反向传播沿着计算图把梯度从 loss 传回每一个参数，链式法则是它的数学基础。
自动微分框架把每个算子记成节点，前向时建图，反向时按拓扑序回传梯度。
梯度校验用中心差分近似数值梯度，和 autograd 的梯度对比，误差应小于 1e-4。
Adam 优化器对一阶矩和二阶矩做指数滑动平均，并做偏置修正后再更新参数。
学习率调度常见做法是预热若干步后按余弦曲线衰减到零。
梯度裁剪按全局范数缩放梯度，防止个别 batch 的异常梯度把训练带崩。
训练集用来更新参数，验证集用来判断是否过拟合，两者必须严格隔离。
困惑度是交叉熵的指数，困惑度越低说明模型对下一个 token 越确定。
token 准确率只看 argmax 是否命中，比困惑度更直观但粒度更粗。
校准度衡量模型说的置信度和实际正确率是否一致，常用 ECE 指标衡量。
评估数据集要按主题和长度分层抽样，并做去重与泄漏检查。
数据泄漏指验证集里出现了训练集的内容，会让所有评估指标虚高。
清洗语料时要去掉空行、超短行和重复行，否则模型会学会输出无意义的重复。
打包是把多条语料首尾相接再滑窗，能减少 padding 带来的算力浪费。
监督微调用指令、输入、答案三元组数据，让通用模型学会遵循指令。
只在答案区计算 loss，指令部分被 mask 掉，模型才不会去学「背题目」。
LoRA 用低秩分解 W + (α/r)·B·A 表示增量，A 随机初始化、B 全零初始化。
B 全零保证注入 LoRA 的瞬间模型输出与基座完全一致，这是等价性证明的起点。
LoRA 只训练 A 和 B，基座权重全程冻结，可训练参数通常只占百分之几。
QLoRA 把基座量化成 NF4，再在量化权重上训练 LoRA，显存因此大幅下降。
NF4 是分位量化，把权重按分位数映射到 16 个非均匀的档位上。
双量化把量化尺度本身再量化一次，每个块通常还能再省零点几个比特。
训练完成后可以把 LoRA 增量合并回基座，推理时不再有额外开销。
检查点要保存权重、优化器状态和训练步数，才能做到真正的断点续训。
推理时每生成一个 token 都要重算整个序列，KV Cache 把 K 和 V 缓存下来避免重复计算。
KV Cache 的显存随 batch 和序列长度线性增长，长上下文下会成为瓶颈。
PagedAttention 把 KV Cache 切成固定大小的块按需分配，把显存碎片降到很低。
连续批处理允许新请求在旧请求还没结束时插进来，显著提升吞吐。
量化把浮点权重压成整数，INT8 是每参数 1 字节，INT4 是每参数 0.5 字节。
per-channel 量化按输出通道分别算尺度，误差通常明显小于 per-tensor 量化。
量化会带来精度损失，必须用困惑度和生成质量实测，不能只看压缩比。
贪心解码每步取 argmax，结果确定但容易重复；温度采样按 softmax 概率随机选。
top-k 只保留概率最高的 k 个候选，top-p 只保留累积概率达到 p 的最小候选集。
温度越高分布越平，生成越发散；温度趋近于零就越接近贪心。
重复惩罚抑制已经出现过的 token，是缓解生成复读的实用手段。
流式返回把生成的 token 逐个推给客户端，首字延迟因此大幅下降。
OpenAI 兼容接口用 messages 数组表达多轮对话，用 SSE 事件流表达流式增量。
服务端要记录请求数、错误数、延迟分位数和 token 吞吐，否则线上问题无从排查。
并发压测用多个工作线程同时发请求，观察吞吐是否随并发线性增长。
RAG 先检索相关文档片段，再让模型基于片段作答，能显著降低幻觉。
文档切分要兼顾语义完整和长度上限，常用固定长度加重叠的方式。
Embedding 模型把文本变成向量，余弦相似度衡量两个向量的语义距离。
向量数据库负责存向量并做近似最近邻检索，Chroma 是常用的轻量选择。
重排器对召回的候选做精排，把最相关的片段排到上下文最前面。
上下文装配要把检索到的片段和指令拼成一个 prompt，并标注来源。
Agent 在模型之外加上工具，让模型能查资料、算数、执行代码。
ReAct 循环是思考、行动、观察三步交替，直到任务完成或达到步数上限。
Function Calling 用 JSON Schema 描述工具签名，模型输出结构化参数。
工具调用结果要以独立的 tool 消息回传，不能混进用户消息里。
MCP 用 JSON-RPC 2.0 在进程之间暴露工具，stdio 是最常用的传输方式。
多步任务要先显式规划，再按依赖拓扑执行，失败要能向上传播。
Python 的虚拟环境隔离依赖，requirements 或 pyproject 描述依赖清单。
类型标注让函数签名自带文档，也让静态检查工具能提前发现问题。
异步 IO 用事件循环在等待网络时不阻塞线程，是高并发服务的基础。
FastAPI 用类型标注自动生成接口文档，SSE 可以很自然地实现流式输出。
日志要带时间戳、级别和上下文，出问题时才追得清链路。
单元测试覆盖核心不变量，集成测试验证端到端链路，两者缺一不可。
配置要集中管理并可从文件加载，避免超参数散落在代码各处。
随机种子必须固定并在报告中写明，否则实验无法复现。
实验记录要包含环境、参数、指标和结论，只记结论的实验等于没做。
基线模型是对比的参照，没有基线的指标数字没有任何意义。
消融实验每次只改一个变量，才能把这个变量的效果单独归因。
误差分析要看具体错例，平均指标会掩盖掉系统性的失败模式。
模型规模越大，需要的显存越多，权重、激活、优化器状态都要算进去。
批大小影响显存和收敛，太大会显存溢出，太小会让梯度噪声变大。
过拟合的表现是训练损失持续下降但验证损失开始回升。
正则化、早停和更多的数据是对抗过拟合的三种常用手段。
早停按验证指标在若干轮不再改善就停止训练，并回滚到最优检查点。
混合精度用 float16 或 bfloat16 做前向，能省显存也能提速。
模型服务的健康检查接口要能反映真实依赖状态，而不只是返回 ok。
限流和超时是保护服务的两道闸门，缺一个就可能被慢请求拖垮。
灰度发布先放小流量，观察指标正常后再逐步放大。
观测性包含指标、日志和链路追踪三件事，合起来才能定位问题。
成本账要按 token 计价，输入 token 和输出 token 通常单价不同。
缓存命中能直接省掉一次模型调用，是成本优化里性价比最高的一招。
提示词工程的核心是给足上下文、说清格式、给出示例。
结构化输出让模型返回 JSON，方便下游程序直接消费。
上下文窗口决定了模型一次能看多少 token，超出部分必须截断或压缩。
对话历史会不断变长，需要按 token 预算裁剪，否则会撑爆上下文窗口。
幻觉指模型编造看似合理但错误的内容， grounded 生成是主要缓解手段。
忠实度衡量回答是否只使用了给定资料里的信息，是 RAG 的关键指标。
可追溯的答案要标注引用来源，方便人工核对与纠错。
安全过滤要同时管住输入和输出，越狱攻击往往藏在用户输入里。
数据隐私要求敏感信息不出域，本地部署是常见的技术应对。
模型选型要在效果、延迟、成本三者之间取平衡，没有 universally 最优解。
评测集要和真实使用场景分布一致，否则线上表现会与离线指标背离。
人工评估仍然不可替代，自动指标只能覆盖可量化的那一小部分。
回归测试集要不断积累线上翻车的真实案例，防止修了旧问题引入新问题。
文档和代码必须同步更新，不同步的文档比没有文档更误导人。
交付一个模型不等于交付一个系统，工程链路才是决定成败的部分。
从零实现一遍，才会真正理解框架帮你封装掉的那些细节。
问：什么是 Transformer？答：Transformer 是一种只靠注意力机制建模序列的神经网络架构。
问：什么是 Tokenization？答：Tokenization 是把文本切成 token 并映射成整数 id 的过程。
问：什么是 BPE？答：BPE 是一种子词分词算法，靠反复合并高频相邻符号来构造词表。
问：什么是 Embedding？答：Embedding 是一张查找表，把 token id 映射成向量。
问：为什么需要位置编码？答：因为注意力本身不感知顺序，位置编码用来告诉模型 token 的先后。
问：什么是自注意力？答：自注意力是 softmax(QKᵀ / √d) V，让每个位置按相关性聚合其他位置的信息。
问：什么是因果掩码？答：因果掩码遮住未来位置，保证生成第 t 个 token 时看不到 t 之后的内容。
问：什么是多头注意力？答：多头注意力把向量切成多份并行算注意力，再拼接映射回来。
问：什么是残差连接？答：残差连接把子层的输入直接加到输出上，让梯度有直连通路。
问：什么是 LayerNorm？答：LayerNorm 对每个样本的特征维度做归一化，稳定训练时的数值分布。
问：什么是 Pre-LN？答：Pre-LN 把层归一化放在子层之前，比 Post-LN 更容易训练深层模型。
问：什么是困惑度？答：困惑度是交叉熵的指数，数值越低说明模型对下一个 token 越确定。
问：什么是过拟合？答：过拟合是模型记住了训练集的噪声，表现为训练损失降但验证损失升。
问：什么是早停？答：早停是验证指标连续若干轮不再改善就停止训练，并回滚到最优检查点。
问：什么是梯度裁剪？答：梯度裁剪按全局范数缩放梯度，避免异常大的梯度把训练带崩。
问：什么是学习率预热？答：学习率预热在训练最初若干步从小逐渐升到设定值，避免开局震荡。
问：什么是 LoRA？答：LoRA 用低秩矩阵 B·A 表示权重增量，只训练 A 和 B，基座保持冻结。
问：什么是 QLoRA？答：QLoRA 把基座量化到 4 比特，再在量化权重之上训练 LoRA 适配器。
问：什么是 NF4？答：NF4 是按分位数划分的 4 比特非均匀量化，对正态分布权重更友好。
问：什么是 SFT？答：SFT 是用指令与答案配对的数据做监督微调，让模型学会遵循指令。
问：什么是 KV Cache？答：KV Cache 缓存已算过的 K 和 V，让每步只算新 token，避免重复计算。
问：什么是 PagedAttention？答：PagedAttention 把 KV Cache 切块按需分配，把显存碎片降到很低。
问：什么是连续批处理？答：连续批处理让新请求随时插进正在跑的批次，提升 GPU 利用率与吞吐。
问：什么是量化？答：量化把浮点权重压成低位整数，用精度换显存与带宽。
问：什么是 INT8？答：INT8 是每参数 1 字节的对称量化，通常配 per-channel 尺度使用。
问：什么是 RAG？答：RAG 先检索相关资料再让模型基于资料作答，用来降低幻觉。
问：什么是向量数据库？答：向量数据库存储 embedding 并支持近似最近邻检索。
问：什么是重排？答：重排是对召回候选做精细打分，把最相关的片段排到前面。
问：什么是 Agent？答：Agent 是能自主规划并调用工具完成多步骤任务的模型系统。
问：什么是 Function Calling？答：Function Calling 让模型按 JSON Schema 输出结构化的工具调用参数。
问：什么是 MCP？答：MCP 是用 JSON-RPC 暴露工具与资源的协议，让工具能跨进程复用。
问：什么是流式输出？答：流式输出把生成的 token 逐个推给客户端，显著降低首字延迟。
问：什么是温度采样？答：温度采样按 softmax(logits / T) 随机选下一个 token，T 越大越发散。
问：什么是 top-p？答：top-p 只在累积概率达到 p 的最小候选集里采样，兼顾多样与稳定。
问：什么是幻觉？答：幻觉指模型生成看似合理但与事实不符的内容。
问：什么是对话历史裁剪？答：对话历史裁剪按 token 预算保留最近轮次，防止撑爆上下文窗口。
问：什么是校准度？答：校准度衡量模型的置信度与真实正确率是否一致，常用 ECE 衡量。
问：什么是数据泄漏？答：数据泄漏指验证集混入了训练内容，会让评估指标虚高。
问：什么是基线？答：基线是用来对照的基准模型或基准方案，没有基线的指标无法判断好坏。
问：什么是消融实验？答：消融实验每次只改变一个变量，用来把这个变量的效果单独归因。
自注意力的复杂度是序列长度的平方，长文本因此必须做分块或稀疏化。
KV Cache 让推理从每步 O(n²) 降到 O(n)，但显存占用随并发数线性上升。
批大小、序列长度和并发数三者相乘，决定了服务端的显存峰值。
预填充阶段一次性算完整个 prompt，解码阶段每次只算一个新 token。
首字延迟主要由预填充决定，吞吐主要由批处理策略决定。
温度越高，生成的多样性越高，但事实性通常越差。
采样策略的选择应该跟着场景走：摘要求稳用低温，创意写作用高温。
重复惩罚过大反而会破坏专有名词，一般取 1.05 到 1.2 之间。
停止条件要同时考虑 EOS、最大长度和自定义停止串，否则请求会跑满预算。
上下文窗口不够时只能截断，截断策略通常是保留 system 与最近几轮对话。
把长文档拆成块再分别摘要，是绕过上下文窗口的常用办法。
指令微调让模型学会「按格式回答」，预训练只让它学会「接着写」。
偏好对齐让模型学会「什么样的回答更好」，常用做法是人类反馈强化学习。
奖励模型把「好回答」变成一个可优化的标量信号。
对齐税指的是对齐之后模型在某些能力上反而变弱的现象。
领域适配的顺序通常是：继续预训练、指令微调、偏好对齐。
继续预训练用领域文本接着训，让模型熟悉行业术语和表达习惯。
灾难性遗忘指学了新任务之后旧能力大幅退化，需要用混合数据缓解。
混合通用数据能显著减轻灾难性遗忘，代价是训练时间变长。
数据质量比数据数量更重要，噪声数据会直接教会模型说错话。
去重、过滤、格式化是数据清洗的三件基本功。
标注一致性低的数据集训练出来的模型表现也会不稳定。
合成数据能快速扩量，但必须抽样人工核对，否则会放大模型的偏见。
评估集要定期更新，否则模型会对固定评测集过拟合。
在线 A/B 实验是验证模型效果的最终手段，离线指标只是前置筛选。
延迟、成本和效果构成不可能三角，优化通常只能改善其中两项。
小模型在特定窄任务上完全可能超过大模型，前提是任务边界足够清晰。
路由策略把简单请求交给小模型、复杂请求交给大模型，是降本的常见做法。
缓存相似问题的答案能显著降低重复请求的成本。
流式输出对用户体验影响巨大，哪怕总耗时不变也显得更快。
前端要处理流式数据的增量拼接与渲染节流，否则会出现卡顿。
断线重连要带上已经收到的 token 数，避免从头重传。
超时时间要分层设置：连接超时、读取超时、整体超时各不相同。
重试必须有退避和上限，否则会把偶发故障放大成雪崩。
熔断器在连续失败后快速失败，给下游留出恢复时间。
限流要按用户维度而不是只按实例维度，否则单个用户就能打满配额。
幂等设计让重复请求不产生副作用，重试才有意义。
灰度发布的指标要提前定好，包括延迟、错误率和业务指标。
回滚方案要在发布前就演练过，不能等出事再想。
模型版本要和提示词版本一起管理，两者不匹配会出现诡异的退化。
提示词模板要纳入版本控制和测试，它其实是代码的一部分。
少样本示例能稳定输出格式，但会占用上下文并可能引入偏差。
思维链让模型先写出推理过程，能提升复杂题的正确率。
自一致性采样多次再投票，用算力换正确率。
检索增强的关键不在检索本身，而在喂给模型的片段是否真的相关。
碎片化切分会把完整语义切碎，所以切分要尽量落在自然段落边界。
重叠切分能缓解边界信息丢失，代价是索引体积变大。
元数据过滤能在检索前先缩小范围，比纯向量检索更可控。
混合检索把关键词检索和向量检索的结果融合，召回通常更稳。
重排模型的输入是「问题 + 候选」，输出是相关性分数。
上下文压缩把多个片段压成更短的摘要，能省下宝贵的窗口。
引用标注让答案可追溯，也是降低幻觉感知的有效手段。
拒答策略要明确：资料不足时说不知道，好过编一个答案。
工具调用需要参数校验，模型给出的参数不一定合法。
沙箱执行模型生成的代码，是能力与安全之间的折中。
权限最小化原则同样适用于 Agent：只给它完成任务必需的工具。
多轮工具调用要有步数上限，否则一次请求可能跑很久。
轨迹日志要完整记录思考与工具结果，否则失败无法复盘。
工作记忆裁剪只保留近期和关键内容，避免上下文被轨迹撑爆。
草稿纸把中间结果外置，能减少主上下文的占用。
失败重试要让模型看到上一次的错误，否则它会重复同样的动作。
多智能体分工能让长任务更可控，代价是通信成本和上下文隔离难度。
评估 Agent 要看任务完成率，而不只是单步回答质量。
单元测试验证函数级正确性，是重构的安全网。
集成测试验证模块之间的契约，最能发现接口漂移。
回归测试把已知缺陷固化成用例，防止二次引入。
快照测试对比输出的完整快照，适合验证格式化逻辑。
属性测试用随机输入验证不变量，比枚举用例覆盖更广。
测试覆盖率是手段不是目的，百分之百覆盖也可能没有断言。
持续集成把测试自动化，让问题在合入前被发现。
代码评审的重点是设计而非风格，风格交给格式化工具。
文档要写「为什么」，代码本身已经说明了「是什么」。
架构决策记录把取舍写下来，半年后才知道当初为什么这么选。
技术债要显式登记，否则它会以故障的形式突然出现。
可维护性来自清晰的边界，模块之间只通过窄接口通信。
依赖越少越可靠，每引入一个依赖都要评估维护活跃度。
版本锁定能保证构建可复现，锁文件必须入库。
环境变量管理配置，密钥不进代码库是最低要求。
日志分级让生产环境只看错误，排查时再开调试级别。
结构化日志便于检索和聚合，纯文本日志在规模上来后没法用。
链路追踪把一次请求串起来，跨服务的性能问题才查得动。
指标要有基线和告警阈值，没有阈值的指标只是装饰。
容量规划要按峰值而不是均值，否则大促必炸。
成本要按请求维度核算，才能定位到具体哪个功能在烧钱。
问：什么是 RAG 的幻觉？答：指模型没有依据给定资料、自己编出了内容。
问：为什么切分要重叠？答：重叠能避免关键语义正好落在切分边界上被切断。
问：为什么要重排？答：向量召回只看粗粒度相似度，重排能把真正相关的排到前面。
问：什么是上下文压缩？答：把检索到的多个片段压成更短摘要，节省上下文窗口。
问：为什么要标注引用？答：引用让答案可追溯，人工核对时能立刻定位依据。
问：什么时候应该拒答？答：资料不足以支撑结论时应当明确说不知道，而不是编造。
问：什么是思维链？答：让模型先写出推理过程再给结论，能提升复杂题的正确率。
问：什么是自一致性？答：采样多次再投票，用额外的算力换取更高的正确率。
问：什么是对齐税？答：对齐之后模型在某些能力上反而下降，这个损失称为对齐税。
问：什么是灾难性遗忘？答：学新任务后旧能力大幅退化，可用混合数据缓解。
问：什么是继续预训练？答：用领域文本接着训，让模型熟悉行业术语与表达习惯。
问：什么是偏好对齐？答：让模型学会人类更偏好哪类回答，常用人类反馈强化学习。
问：什么是奖励模型？答：把「回答好不好」变成一个可优化的标量分数的模型。
问：为什么数据质量比数量重要？答：噪声数据会直接教会模型说错话，量再大也没用。
问：什么是路由策略？答：按难度把请求分给不同规模的模型，是常见的降本手段。
问：什么是不可能三角？答：延迟、成本、效果三者通常只能同时优化其中两项。
问：为什么要做 A/B 实验？答：离线指标只是前置筛选，真实效果要靠线上实验判定。
问：什么是首字延迟？答：从发出请求到收到第一个 token 的时间，主要由预填充决定。
问：为什么流式输出体验更好？答：用户能立刻看到进展，即使总耗时不变也显得更快。
问：什么是熔断？答：连续失败后直接快速失败，给下游留出恢复时间的保护机制。
问：什么是幂等？答：同一个请求重复执行多次结果一致，这样重试才是安全的。
问：为什么重试要有退避？答：立刻重试会把偶发故障放大成雪崩，退避能削峰。
问：什么是限流？答：限制单位时间内的请求量，防止个别用户打满配额。
问：什么是技术债？答：为了赶进度留下的设计欠账，不登记就会以故障的形式爆发。
问：为什么要写架构决策记录？答：半年后靠它才知道当初为什么做这个取舍。
问：什么是链路追踪？答：把一次请求在所有服务里的路径串起来，用于定位性能问题。
问：什么是结构化日志？答：用固定字段而非纯文本记录日志，便于检索与聚合。
问：为什么要锁依赖版本？答：不锁版本构建就不可复现，出问题时无法还原现场。
问：什么是沙箱执行？答：在受限环境里跑模型生成的代码，是能力与安全之间的折中。
问：为什么要限制 Agent 的工具权限？答：权限最小化能把一次误操作的破坏范围降到最低。
问：为什么要给 Agent 设步数上限？答：否则一次请求可能无限循环，时间和成本都失控。
问：什么是轨迹日志？答：记录 Agent 的每一步思考与工具结果，失败时才能复盘。
问：什么是工作记忆裁剪？答：只保留近期与关键内容，避免上下文被长轨迹撑爆。
问：什么是草稿纸？答：把中间结果放到主上下文之外，需要时再取回的机制。
问：为什么要做回归测试？答：把已知缺陷固化成用例，防止修了旧问题又引入新问题。
问：什么是属性测试？答：用随机输入验证不变量，比枚举用例覆盖更全面。
问：为什么覆盖率不是目的？答：百分之百覆盖也可能一条断言都没写，覆盖不等于验证。
问：为什么文档要写为什么？答：代码已经说明了是什么，缺的恰恰是当初的取舍理由。
问：为什么要做容量规划？答：按均值规划会在峰值时崩溃，容量必须按峰值估算。
问：为什么成本要按请求核算？答：只有落到具体功能，才知道是哪个环节在烧钱。
