# Project 02 — AI Assistant Service

## 项目目标

把 Project 01 的 CLI Assistant 升级为真正的 Python 工程化服务，获得工程能力。

## 为什么需要这个项目

Project 01 证明了 Python 能调用 LLM，但代码还是脚本级的：没有虚拟环境、没有测试、没有异步、没有类型提示。这些问题不解决，项目无法继续扩展。

## 最终能力

- Python 工程化（venv / pip / 依赖管理）
- 模块化与测试
- async / await
- FastAPI 服务化
- 日志、配置、错误处理的工程化
