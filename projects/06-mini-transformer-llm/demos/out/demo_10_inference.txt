Project 06 — Mini Transformer LLM
Demo 10: Inference（贪心 / 温度 / top-k 采样）
Python 3.13.12  |  numpy 2.5.3

========================================================================
  1. 训练一个玩具模型（与 Demo 09 同配置）
========================================================================
  训练后 loss ≈ 4.8517（初始 ≈ 6.2100）

========================================================================
  2. 贪心生成（temperature ≤ 0 → 取 argmax，最确定）
========================================================================
  prompt        : 'Transformer'
  贪心生成文本  : 'Transformer               '
  生成 token 数 : 15  (≤ 15)
  全部在词表内  : True

========================================================================
  3. 温度采样（temperature > 0，越高温越随机）
========================================================================
  temperature=1.2 : 'Transformer被则  一个分词器符，用生成越token 词表 除'
  temperature=0.5 : 'Transformer     ，   ，数 用 、'
  → 温度低更聚焦、温度高更发散，符合直觉。

========================================================================
  4. top-k 采样（只在概率最高的 k 个里选）
========================================================================
  top_k=20 : 'Transformer是token，  ， ，，    _。'
  → top-k 把长尾噪声 token 截掉，生成更干净。

========================================================================
  5. 多 prompt 对照（都是玩具规模，内容可能重复属正常）
========================================================================
    prompt=        '模型' → '模型          '
    prompt= 'Attention' → 'Attention          '
    prompt=     'token' → 'token          '

  Demo 10 结束
