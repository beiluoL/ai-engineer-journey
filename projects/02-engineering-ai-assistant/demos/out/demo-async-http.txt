===== 1. 串行 vs 并发（同一个 AsyncClient，3 个请求）=====
  串行 for + await     : 0.944s
  并发 asyncio.gather  : 0.313s
  提速                 : 3.02x
  → 单个请求没有变快，省掉的是「等第一个回来才发第二个」的等待

===== 2. AsyncClient 的生命周期：async with 负责关连接池 =====
  刚创建，还没退出 async with：is_closed = False
  在 async with 里发完请求 ：is_closed = False
  退出 async with 之后      ：is_closed = True
  → 不关 = 连接池和 TCP 连接泄漏；每个请求 new 一个 = 反复握手的额外开销

===== 3. 两类错误要分开接 =====
  (a) 超时   → httpx.TimeoutException: ReadTimeout
  (b) 连不上 → httpx.ConnectError: All connection attempts failed
  → 超时要重试，连不上要告警；混成一句 except Exception 就没法分别处理
