# Project 07 — Local Open Source LLM

## 项目目标

接触真实开源模型生态，在本地跑通 Hugging Face 模型。

## 为什么需要这个项目

生产环境不可能每次都调商业 API。需要掌握如何加载、运行、对比开源模型，以及它们的限制和优势。

## 最终能力

- Hugging Face Transformers
- Tokenizer 深入理解
- Model Loading（device / dtype）
- Datasets 库
- 模型对比与选型
- 本地推理优化
