== 生成的回答 ---------------------------------------------------------------
   ThreadLocal 的 ThreadLocalMap 中，key 是 ThreadLocal 的弱引用，value 是强引用。当 ThreadLocal 外部引用置 null 后，key 会被 GC 回收变成 null，但 value 仍被 Entry 强引用，无法回收，导致泄漏。线程池中线程长期存活，泄漏会累积。

正确姿势：使用完务必在 finally 中调用 remove() 清理，尤其在线程池场景。
