== 方法：标准 decoder-only 参数公式 ---------------------------------------------
   embed      = vocab × hidden        （token 嵌入表）
   lm_head    = 同上，tie 权重时为 0   （输出投影头）
   attn/layer = h×q_dim + 2×(h×kv_dim) + q_dim×h   （q/k/v/o，注意 K/V 按 kv_heads 算 → GQA）
   mlp/layer  = 3 × hidden × inter    （gate + up + down，SwiGLU 结构）
   每层再 + 2 个 LayerNorm = 2×hidden；最后还有一个 final norm = hidden
