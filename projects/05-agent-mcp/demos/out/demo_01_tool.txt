② 检索即工具：Agent 版 RAG 的入场券
==========================================================================
  [1] Project 04 会话与多轮（p04-session）：Turn 不可变、会话落盘走 mkstemp+fsync+os.replace 原子写，历史拼进 prompt 的顺序是 system 历史 本次提问。
  [2] Project 04 Personal RAG（p04-rag）：解析分块 embedding 向量库相似度检索重排上下文组装，最后拼成一条带引用的回答。

  —— 关键区别：检索不再藏在 pipeline 里，而是被模型当工具决定要不要调。

==========================================================================
③ 工具执行结果永远是 ToolResult，不是「抛异常 / 返回值」二选一
==========================================================================
  正常  → ok=True  output='[1] Project 05 Research Agent（p05-agent）：Tool '
  失败  → ok=False  error='未知工具「不存在」。当前可用：calculator, now, rag_search'

  ToolResult.render() 对模型来说没有区别：
    [工具执行失败] 不存在: 未知工具「不存在」。当前可用：calculator, now, rag_search

④ 计算工具：给模型算数，但绝不给它代码执行权
==========================================================================
  calculator('(12+8)*3/7') = 8.571428571428571
  calculator('2**10') = 1024
  calculator('17//5') = 3
  同一串输入交给 eval → 成功执行，读到了当前目录：/Users/beiluo/Documents/alProject/ai-engineer-journey/projects/05-agent-mcp
  同一串输入交给 calculator → 直接拒绝：不允许的表达式成分：Call（例如函数调用、名称引用都被禁用）
