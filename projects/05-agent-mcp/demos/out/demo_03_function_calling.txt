==========================================================================
④ 关键顺序：assistant 必须在 tool 之前
==========================================================================
  role 序列 = ['user', 'assistant', 'tool', 'assistant']
  assistant 在索引 1，tool 在索引 2 → 顺序正确 ✓
  这条规则服务端会校验，离线 mock 里永远复现不出来。

  ok = False
