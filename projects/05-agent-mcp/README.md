# Project 05 — Research Agent

## 项目目标

让 AI 不只是回答，而是能自主规划和调用工具。

## 为什么需要这个项目

RAG 解决了知识问题，但 AI 还不能主动做事。Agent + MCP 是让 AI 从"问答"到"做事"的关键一跃。

## 最终能力

- Function Calling 高级用法
- Agent 循环（Plan → Act → Observe）
- Tool 设计与注册
- MCP 协议
- Agent Workflow（多 Agent 协作）
- Memory（短期 / 长期）
