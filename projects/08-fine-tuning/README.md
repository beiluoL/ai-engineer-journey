# Project 08 — Fine-tuning

## 项目目标

掌握模型微调，让通用模型变成领域模型。

## 为什么需要这个项目

RAG 是外挂知识，Fine-tuning 是把知识和行为"烧进"模型。生产中 LoRA / QLoRA 是标配，必须掌握。

## 最终能力

- SFT（Supervised Fine-Tuning）
- PEFT / LoRA / QLoRA
- 训练数据准备
- 训练参数与超参
- 显存优化
- 合并 / 导出微调模型

## 项目演进

↓ 模型定制化
