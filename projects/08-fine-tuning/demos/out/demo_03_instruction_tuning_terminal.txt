── 3. 对照实验：A 只算答案区 / B 全序列都算（各训 60 步，其余完全相同） ─────────────────────────────────
  微调前 答案区困惑度                             3,649.91
  微调前 prompt 区困惑度                        2,204.15

  A组(只算答案) 首步 loss                       8.2909
  A组(只算答案) 末步 loss                       6.1882
  A组 答案区困惑度                              426.19
  A组 prompt 区困惑度                         1,184.91

  B组(全序列) 首步 loss                        8.1916
  B组(全序列) 末步 loss                        6.1210
  B组 答案区困惑度                              454.49
  B组 prompt 区困惑度                         119.94

── 4. 结果对比 ───────────────────────────────────────────────────────────────────
  指标           微调前      A组 只算答案区  B组 全序列  谁更好
  -----------  -------  --------  ------  ---
  答案区困惑度       3,649.9     426.2   454.5    A
  prompt 区困惑度  2,204.2   1,184.9   119.9    B
  答案区 CE        8.2025    6.0549  6.1192    A
  答案区困惑度：B 相对 A                          +6.64%   正数 = B 更差
  prompt 区困惑度：B 相对 A                     -89.88%   负数 = B 更会背问题

── 5. 本 demo 的关键数字 ───────────────────────────────────────────────────────────
  mask 覆盖的 token 占比                      81.41%
  答案区困惑度 微调前 → A组                        3,649.9 → 426.2（↓88.3%）
  答案区困惑度 微调前 → B组                        3,649.9 → 454.5（↓87.5%）
  只算答案区带来的收益                             答案区困惑度再降 6.64%

  读法：B 组把一部分梯度拿去拟合 prompt 了 —— 它的 prompt 区困惑度确实更低，
  但那是「背下了用户会问什么」，不是「学会了怎么回答」。答案区才是我们要的指标。
  59 条数据、60 步的规模下差距不算夸张，但方向稳定，且步数越多差距越明显。
