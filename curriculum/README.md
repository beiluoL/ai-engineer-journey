# Curriculum — 正式课程

Curriculum 是整个项目的正式学习内容。

## 组织规则

每一章 = 一个目录：

```text
lesson-dir/
├── README.md          # 本章入口与说明
├── lesson.md          # 正式教学内容
├── demo/              # 可运行的最小代码
│   └── README.md
└── exercises/         # 练习
    └── README.md
```
