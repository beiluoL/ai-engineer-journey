# 练习 — 01 Variables

> 对应 [Lesson 01 — 变量、类型与输入输出](../../lessons/01-variables/)

## 练习原则

```text
基础题 → 理解题 → 代码题 → 项目题
```

## 题目

### 基础题

1. 写出 5 种基础类型的变量，用 type() 打印它们的类型
2. 用 input() 接收用户的名字，用 f-string 输出问候语

### 理解题

3. `input()` 默认返回什么类型？需要整数时怎么做？
4. 下面代码合法吗？为什么？
   ```python
   x = 10
   x = "hello"
   ```

### 代码题

5. 写一个程序：接收用户的名字和年龄，输出：
   ```text
   你好，xxx
   你今年 xx 岁
   ```

### 项目题

6. 在 [Project 01](../../projects/01-python-ai-cli/) 的 src/main.py 基础上，
   增加一个"学习天数"的输入（int），用 f-string 输出完整学习档案。
