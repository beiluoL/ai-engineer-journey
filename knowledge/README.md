# Knowledge — 知识索引与关系

> Knowledge 是索引和关系层，不是第二套课程正文。

## 三个维度

```text
knowledge/map/      知识关系地图
knowledge/glossary/ 术语定义
knowledge/concepts/ 概念卡片（是什么 + 与谁相关 + 前置/后置 + 项目/实验）
```

## 核心原则

**不要把课程正文复制到这里。**

Knowledge 负责：

```text
概念是什么
与谁相关
前置知识
后置知识
对应项目
对应实验
```

避免一份知识维护三遍。
