# 02-ai-application — Phase 2：AI Application

> 用 Python 真正调通一次 LLM，搭建可交互的 AI Chat Web 应用。

## 这一阶段学什么

- HTTP / API 调用与 JSON 处理
- FastAPI 与 Pydantic 数据校验
- LLM API 调用与 Prompt 设计
- SSE / Streaming 流式输出
- 前后端联调（Vue + FastAPI）
- 会话与上下文管理

## 为什么学

这是从「会 Python」到「会做 AI 应用」的关键一跳。掌握 LLM API 调用、流式输出、Prompt 工程，就能独立做出可演示的 AI Web 产品，后续 RAG / Agent 都建立在这层之上。

## 核心技能

- 用 FastAPI 搭建 RESTful 服务
- 用 Pydantic 定义请求 / 响应模型
- 调用 OpenAI 兼容的 LLM API
- 实现 SSE 流式响应
- 设计多轮对话 Prompt
- 用 Vue 前端对接后端 API
