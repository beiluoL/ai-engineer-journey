# Mistakes — 错误记录系统

> 教程让人「看懂」，错误记录让人「真正掌握」。每个真实踩过的坑都值得一条记录。

## 记录格式

每个错误一个文件：`mistakes/YYYY-MM-DD-slug.md`，结构固定：

```markdown
# 标题
## 问题        （当时想做什么）
## 我的错误答案 / 做法与现象
## 为什么错    （根因，不是表面现象）
## 正确理解
## 代码示例    （最小复现 + 修复对比）
## 如何避免    （checklist / 习惯 / 工具）
## 复习时间    （间隔重复：3 天 / 2 周 / 2 月后再看一遍）
```

## 规则

- 只记录**真实踩过**的坑，不收集「听说会错」的条目
- 与某 Project 强相关时，在该项目 README 或 milestone 里加一行交叉引用
- 复习时确认真懂了，就在记录头部打 `🧠 已复习（日期）`
